# 对照实验：静态授权快照 vs 动态授权源

## 变量

唯一主变量是授权来源。其余全部固定：

| 固定项 | 取值 |
| --- | --- |
| 契约 | `p3-authz-contract-v0.1` |
| Fixture | `public-good` |
| 检查顺序 | `T01, T06, T02, T04, T03, T05` |
| 预算 | 8 次尝试 / 8 轮 / 90 逻辑秒 |
| 撤权时点 | 第 2 次检查执行之后 |
| 撤权对象 | `T02` |

## 运行

```text
python scripts/compare_strategies.py --scenario good --after-attempt 2 --revoke-test T02
```

## 观测结果

| 指标 | 静态快照 | 动态源 |

| 实际尝试 | 6 | 5 |

## 结论边界

- 该差异只能归因于授权来源，因为其余条件完全相同。
- 这是**模拟**结果，不能外推为真实服务的权限行为。
- 未覆盖列表如实列出 `T02`，不得表述为"没有问题"。
- 不承诺在途动作瞬时取消；本次运行中撤权发生在检查之间，边界已记录。
