## 4. 项目简介（200—400 字）

```text
本项目为 P3 授权边界测试 Agent，目标是在教师批准的本地教学文档服务上，用一组注册检查验证授权边界，并输出他人可复核的证据与报告。首版范围：一个模拟目标、两名虚构用户、两份文档及附件、六项注册检查、固定预算与单并发；先完成模拟器与独立控制器，再接入批准的执行环境。

与队友的调度策略对照不同，本组路线以授权状态为一等对象：把授权做成可版本化的来源，对照「静态授权快照」与「动态授权源」两种策略，验证运行中撤权、在途动作边界、重新授权与恢复是否符合契约，并保持拒绝记录不可覆盖。

交付包括可运行的最小切片、注册表与独立控制器、六项检查执行与原始证据落盘、三类结论状态、覆盖与停止说明，以及规格、状态模型、验收矩阵和交接说明。不做任意 URL 与任意 Shell 执行，不接真实资产，不承诺瞬时取消。所有结论标明证据来源与强度，模拟结果不冒充真实执行，AI 产出不替代本人实现、验证与签署。
```
